# 开发与验证

## 代码结构

- `native/BPStudio.Desktop`：WPF 宿主、音频、界面桥接、报告导出。
- `native/BPStudio.Core`：数据、存储、模型接口、九项诊断、语音管理与报告内容。
- `native/BPStudio.App/RecordingSession.cs`：桌面端复用的录音组件；本快照不包含旧版 WinUI 应用。
- `ui/src`：React 与 TypeScript 界面。
- `native/*Tests` 和 `scripts/test-*.py`：核心、导出、语音及隔离桌面验证。
- `docs/screenshots`：当前版本界面截图，内容为明确标注的演示材料。

## 构建

开发环境需要 Windows x64、.NET 8 SDK、Node.js、pnpm 和 Python。使用者直接下载 Release 即可。

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File scripts/build-desktop.ps1 -Publish -BundleWebView
```

构建脚本准备并校验专用语音与 WebView2 资源、安装锁定的前端依赖、构建界面，再发布 Windows 桌面程序。首次准备资源需要联网；缓存位于 `.cache`，不提交到仓库。程序目录生成在 `release/BP-Studio-0.4.1-Desktop-Windows-x64`。

只有明确需要分发 ZIP 时运行：

```powershell
python scripts/distribute-desktop.py
```

该脚本核对语音和 WebView2 校验清单、收集许可、排除用户资料与测试缓存，再生成 ZIP 与 SHA-256。固定运行环境需要随项目维护更新；本次 Release 内置版本见第三方组件说明。

## 核心和界面验证

```powershell
# 生成合成反馈样本，并检查诊断、兼容、存储和本机 HTTP 接口
# 第二个参数是输出目录，不是现有用户资料目录
dotnet run --project native/BPStudio.Feedback.Tests -- test-results/feedback-0.4.1

# 已先发布 0.4.1，并安装 Python Playwright 后运行
python scripts/test-deep-feedback.py
python scripts/test-back-to-top.py

# 生成三份合成报告，使用实际 DOCX/PDF 导出器
dotnet run --project native/BPStudio.Export.Tests -- test-results/report-export

# 对指定程序目录进行空白用户与便携界面检查
python scripts/test-portable-desktop.py prepare --exe release/BP-Studio-0.4.1-Desktop-Windows-x64/BPStudio.exe
python scripts/test-portable-desktop.py inspect
python scripts/test-portable-desktop.py close
```

UI 检查通过本机 WebView2 调试端口驱动应用，使用独立资料目录。不要把正式资料目录当作测试输出目录。语音全量测试还需要先准备脚本要求的合成音频样本；对应脚本与语音测试项目已保留。

便携验证使用空白资料、无系统 Python 的路径环境，确认内置 Base 可自动离线准备。真实用户资料保持不变。本机 HTTP 测试使用合成反馈，未证明真实模型的教学评价准确性；界面截图也不是模型性能评测。上述结果来自本地 Windows 11 环境，并不表示每个设备、音频编码或服务商都已覆盖。
